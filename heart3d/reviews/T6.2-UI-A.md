## Implemented scope

- Explore is the default: tap a structure to highlight it, show one callout with a leader outside the viewer, and open the existing card. Anatomy highlights use existing exported label/cavity/AHA IDs; graph highlights reuse the graph renderer.
- Relevant reads `EXPLORE_DATA.RELEVANT_LABELS[view]` in `explore-data.js`. Every shipped list is empty with `TODO(content)` in the source. The UI explains the empty list and invites tapping; a tapped unlisted structure remains visible. All shows geometrically eligible labels within the enabled groups.
- Above 900 px, callouts occupy two reserved side rails. Normal-flow buttons cannot overlap; crowded rails scroll. At 900 px and below, one callout occupies the reserved footer. At 1700 px and above the card sits beside the viewer; otherwise it sits below. Legends are outside the canvas, with reserved status space to prevent toggle-induced layout shifts.
- Cut surfaces remain opaque, including when Conduction is enabled. Choosing any cut turns coronaries off; the user can explicitly re-enable them. See-through replaces the X-ray control and is available only in External mode.
- Network resting colour is green-teal, impulse white, muscle wave amber with a fading amber tint. Existing red torus/cross block geometry is retained; the legend includes a red cross.
- Activation timing map replaces the Isochrones label under Advanced. `UI_FLAGS.activationTimingMap` ships false. The control is hidden and the API rejects enabling it while the flag is false.

No changes to anatomical coordinates, mesh exports, conduction specification/generator, solver/seeds, clinical cards, rhythm text or ECG calibration. Only viewer instructions/control names changed. Shared CSS is included in Pathology's rebuilt page; its existing suite is also exercised.
